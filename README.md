# 📚 Notes App (Express + EJS + MongoDB)

A simple Notes App built using **Node.js, Express, EJS and MongoDB**.  
This project helps understand routing, views, CRUD operations, and MongoDB connections.

---

## 🚀 Features

- ➕ Add new notes  
- 👁️ View all notes  
- 🔍 Search notes by title  
- ❌ Delete notes  
- 🖥️ Clean EJS-based UI  
- 💾 MongoDB for data storage

## ▶️ How to Run This Project

### 1️⃣ Clone the repository

```bash
git clone https://github.com/arbazansari7933/notes-app.git
```

### 2️⃣ Install dependencies

```bash
npm install
```

### 3️⃣ Start the server

```bash
node server.js
```

### 4️⃣ Open in browser

```
http://localhost:3000/
```
